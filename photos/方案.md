要编写一个能通用于不同尺寸和分辨率 Mac 的脚本，核心需要解决两个问题：**坐标映射自动修正** 和 **图像识别尺度适应**。以下方案可以让你的脚本在任意 Mac 上几乎无需修改地运行。

---

## 🧠 通用方案的核心逻辑

### 1️⃣ 自动检测并修正 Retina 坐标缩放
Mac 的 Retina 屏幕存在 **物理像素** 与 **逻辑点** 的区别。  
`pyautogui.locateOnScreen()` 返回的坐标是**物理像素坐标**，而鼠标点击函数 `pyautogui.click()` 期望的是**逻辑点坐标**。  
缩放因子 `scale_factor` 一般为 2.0（Retina）或 1.0（非 Retina），但某些 Mac 的缩放设置可能为 1.5 等非整数。

**自动获取缩放因子**（无需用户手动填写）：  
借助 `pyobjc` 调用 macOS 原生 API 获取当前主显示器的 `backingScaleFactor`。

### 2️⃣ 图像识别多尺度匹配（可选增强）
如果希望同一张 `target.png` 在不同缩放比例下都能被识别，可以对图像进行缩放匹配。  
更简单的做法是：**在系统默认缩放下截取目标图**，因为大多数用户不会改动缩放设置。

## 🔧 通用代码实现

将以下代码替换或整合到你的脚本中，即可自动适应任何 Mac 的分辨率和缩放。

```python
import pyautogui
import time
import random
import os
import math
from Quartz import CGDisplayBounds, CGMainDisplayID

# === 自动获取屏幕缩放因子 ===
def get_scale_factor():
    """获取主显示器的物理像素/逻辑点缩放比例"""
    main_display = CGMainDisplayID()
    # 获取显示器的物理像素尺寸
    width_px = CGDisplayPixelsWide(main_display)
    # 获取显示器的逻辑点尺寸
    bounds = CGDisplayBounds(main_display)
    width_pt = bounds.size.width
    return width_px / width_pt if width_pt > 0 else 1.0

SCALE_FACTOR = get_scale_factor()
print(f"🔍 检测到屏幕缩放因子: {SCALE_FACTOR}")

# === 图片配置 ===
IMAGE_NAME = 'target.png'
CONFIDENCE = 0.8
CHECK_INTERVAL = 0.5
SEARCH_REGION = None  # 可按需设置 (left, top, width, height)

pyautogui.FAILSAFE = False

def get_image_path():
    return os.path.join(os.path.dirname(os.path.abspath(__file__)), IMAGE_NAME)

def to_logical_point(physical_x, physical_y):
    """将物理像素坐标转换为逻辑点坐标"""
    return (physical_x / SCALE_FACTOR, physical_y / SCALE_FACTOR)

def to_physical_point(logical_x, logical_y):
    """将逻辑点坐标转换为物理像素坐标（一般用不到）"""
    return (logical_x * SCALE_FACTOR, logical_y * SCALE_FACTOR)

# --- 贝塞尔曲线函数（不变）---
def get_bezier_point(t, p0, p1, p2, p3):
    u = 1 - t
    tt, uu = t * t, u * u
    uuu, ttt = uu * u, tt * t
    x = uuu * p0[0] + 3 * uu * t * p1[0] + 3 * u * tt * p2[0] + ttt * p3[0]
    y = uuu * p0[1] + 3 * uu * t * p1[1] + 3 * u * tt * p2[1] + ttt * p3[1]
    return (x, y)

def human_move(target_x, target_y, duration):
    """拟人化移动（坐标已为逻辑点）"""
    start_x, start_y = pyautogui.position()
    dist = math.hypot(target_x - start_x, target_y - start_y)
    if dist < 50:
        pyautogui.moveTo(target_x, target_y, duration=duration, tween=pyautogui.easeOutQuad)
        return

    offset = dist * random.uniform(0.2, 0.5)
    cp1_x = start_x + (target_x - start_x) * 0.3 + random.uniform(-offset, offset)
    cp1_y = start_y + (target_y - start_y) * 0.3 + random.uniform(-offset, offset)
    cp2_x = start_x + (target_x - start_x) * 0.7 + random.uniform(-offset, offset)
    cp2_y = start_y + (target_y - start_y) * 0.7 + random.uniform(-offset, offset)

    steps = max(int(duration * 60), 10)
    old_pause = pyautogui.PAUSE
    pyautogui.PAUSE = 0
    start_time = time.time()

    for i in range(steps + 1):
        progress = i / steps
        eased = 1 - (1 - progress) * (1 - progress)
        x, y = get_bezier_point(eased, (start_x, start_y), (cp1_x, cp1_y), (cp2_x, cp2_y), (target_x, target_y))
        pyautogui.moveTo(x, y)
        elapsed = time.time() - start_time
        expected = duration * progress
        if expected > elapsed:
            time.sleep(expected - elapsed)

    pyautogui.moveTo(target_x, target_y)
    pyautogui.PAUSE = old_pause

def simulate_human_click(location):
    """点击流程：自动修正坐标"""
    if location:
        # 1. 获取物理像素中心点
        physical_x, physical_y = pyautogui.center(location)
        # 2. 转换为逻辑点
        logical_x, logical_y = to_logical_point(physical_x, physical_y)
        # 3. 随机偏移（单位：逻辑点）
        final_x = logical_x + random.randint(-5, 5)
        final_y = logical_y + random.randint(-5, 5)

        print(f"✅ 发现目标！逻辑坐标: ({final_x:.1f}, {final_y:.1f})，正在移动...")
        move_time = random.uniform(0.5, 1.2)
        human_move(final_x, final_y, duration=move_time)
        time.sleep(random.uniform(0.1, 0.2))
        pyautogui.click()
        return True
    return False

def main():
    target_path = get_image_path()
    print("=" * 40)
    print("🤖 通用 Mac 自动点击器（自动适配缩放）")
    print(f"📂 监听图片: {IMAGE_NAME}")
    print("🛑 按 Ctrl+C 停止")
    print("=" * 40)

    if not os.path.exists(target_path):
        print(f"❌ 找不到文件 {target_path}")
        return

    while True:
        try:
            location = pyautogui.locateOnScreen(
                target_path,
                confidence=CONFIDENCE,
                grayscale=True,
                region=SEARCH_REGION
            )
            if location:
                simulate_human_click(location)
                print("⏳ 点击完成，冷却 3 秒...")
                time.sleep(random.uniform(2.5, 4.0))
        except pyautogui.ImageNotFoundException:
            pass
        except Exception as e:
            print(f"\n⚠️ 错误: {e}")
            print("🔄 3 秒后继续...")
            time.sleep(3)
        time.sleep(CHECK_INTERVAL)

if __name__ == "__main__":
    try:
        main()
    except KeyboardInterrupt:
        print("\n🛑 程序已停止")
```

## 📝 关于截图的通用性建议

| 情况 | 是否需要重新截图 |
|------|------------------|
| 两台 Mac 显示器缩放设置**相同**（如均为默认“看起来像 1440×900”） | ❌ 不需要，一张图通用 |
| 缩放设置**不同**（如一台默认，一台“更多空间”） | ✅ 需要，像素尺寸已变 |
| 截图是物理像素尺寸，且目标应用内容本身是矢量图形（如按钮、文字） | 可考虑启用**多尺度匹配**（见下文高级扩展） |

### 🚀 高级扩展：多尺度匹配（若想彻底不重截图）
在 `locateOnScreen` 循环外增加对截图图像的缩放尝试：
```python
import cv2
import numpy as np

def locate_with_scale(target_img, screen_img, scales=[0.8, 1.0, 1.2, 1.5, 2.0]):
    """在 screen_img 中按不同比例缩放 target_img 进行匹配"""
    for scale in scales:
        resized = cv2.resize(target_img, None, fx=scale, fy=scale)
        result = cv2.matchTemplate(screen_img, resized, cv2.TM_CCOEFF_NORMED)
        _, max_val, _, max_loc = cv2.minMaxLoc(result)
        if max_val >= CONFIDENCE:
            h, w = resized.shape[:2]
            return (max_loc[0], max_loc[1], w, h)
    return None
```
但这样会**显著增加 CPU 开销**，非必要不推荐。保持相同缩放设置截图是最简单的通用方式。

## ✅ 总结

- **自动缩放修正**：通过 `Quartz` 获取 `SCALE_FACTOR`，坐标转换自动化。
- **截图通用性**：建议在所有目标机器上保持相同的显示缩放设置（即系统默认），这样一张图就能走天下。
- **运行**：脚本在 15 寸和 13 寸 Mac 上均可直接使用，无需手动修改任何参数。
